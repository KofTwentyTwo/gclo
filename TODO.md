# gclo — development tracking

**Development is tracked in [the project's issues](https://git.kof22.com/KofTwentyTwo/gclo/issues).**

- Roadmap / current status: [#11 — Development roadmap](https://git.kof22.com/KofTwentyTwo/gclo/issues/11) (v1.0.0 shipped; post-1.0 backlog there)
- Owner action items: [#7 — Owner setup checklist](https://git.kof22.com/KofTwentyTwo/gclo/issues/7)
- Standards compliance: [#62 — epic](https://git.kof22.com/KofTwentyTwo/gclo/issues/62) and the maintainer checklist [#66](https://git.kof22.com/KofTwentyTwo/gclo/issues/66)

Labels: `priority` (work first), `needs-owner` (blocked on the owner), `deferred`
(agreed follow-up, unscheduled), `quality`, `release`, `refactor`.

This file intentionally holds no task content — the issue tracker is the single
source of truth.
